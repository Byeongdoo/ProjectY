# 무명장수 검 확대·북쪽 공격 수정 — 2026-11-22

검을 길고 두꺼운 밝은 은색 도신으로 다시 제작하고, 무명장수 11동작·88방향 클립·608프레임에 반영했다. 정면 기준 이미지와 8방향 기준 이미지도 교체했다. 기존 Unity 파일·클립 GUID는 유지했다.

## 방향과 동작

- 북쪽 공격은 오른손을 어깨 위로 들어 몸 앞쪽으로 내리치는 동작으로 수정했다. 검이 몸 앞에 들어가면 머리와 몸통이 자연스럽게 가린다. 등과 허리 위를 가로지르는 원래 베기는 사용하지 않는다.
- 북동 공격은 같은 전방 동작의 3D 자세를 해당 방향으로 투영한 결과를 사용한다.
- 북서 공격은 올린 검의 기준 이미지에서 PixelLab의 레이어 애니메이션으로 직접 구성했다. 검을 몸의 먼 쪽 레이어에 놓고, 어깨 높이에서 화면 왼쪽 위로 베고 회수한다. 각도는 0→25→30→-20→-40→-45→-15→0도다. 몸체는 원래 픽셀을 복사하고 타격 시 1픽셀의 체중 이동을 준다. 첫·마지막 자세는 일치한다.
- 북쪽 대기는 검을 세운 자세로 시작·끝을 고정해 다시 제작했다. 북쪽의 나머지 동작도 전방 동작과 무구 가림을 지시해 재제작했다.
- 공격 8방향·64프레임의 Trail을 큰 검과 새 동작에 맞춰 다시 제작했다. 북쪽에서 검이 가려지는 구간은 허리·바지의 밝은 픽셀을 검 끝으로 잘못 추적하지 않도록 경로를 지정했다. 효과는 본체 뒤에서 합성한다.

## 크기·발 기준·여백

- 제작 요청은 기존 검 길이·폭의 약 1.5배와 밝은 도신·어두운 외곽선이었다. AI 결과의 실제 도신 길이는 자세와 원근에 따라 다르다.
- PPU는 32이며 몸체의 픽셀 밀도를 유지한다. 이미지 전체를 비율 확대하는 처리는 사용하지 않았다.
- 정면·회전 기준 이미지는 96×96 투명 캔버스다. 발 피벗은 (48,18), 발 기준선은 위에서 78픽셀이다. PixelLab의 정확한 정수 이동으로 기준 이미지의 발을 맞췄다. 자세한 이동량은 `RotationAnchorAlignment.json`에 기록했다.
- 동작 프레임의 발 피벗은 `x = width/2`, `y = 18 + (height-96)/2`다. 기존 64×64 기준의 `(32,2)`와 같은 월드 기준점이다.
- 검이 가장자리에 닿은 65프레임에는 PixelLab에서 128×128 여백과 뾰족한 검 끝을 추가하고 분리된 가장자리 조각을 제거했다. 이 정확한 보정 과정에서 본체 내부의 의도하지 않은 픽셀 변경은 0이다. AI 재편집 단계의 모든 픽셀이 원본과 동일하다는 뜻은 아니다.
- 일부 원본 PNG의 캔버스 크기는 서로 다르다. 클립의 각 스프라이트 피벗으로 위치를 맞추며, 시트는 가장 큰 셀에 가운데 여백을 추가한다. 픽셀을 확대해 셀에 맞추지 않는다.

## Unity 적용·검증

- 저장 위치: `Client/Assets/Resources/Art/Characters/SpiritsV2/MumyeongJangsu/`.
- `Sprites/`에 수정 본체, `SpritesWithTrail/`에 합성본, `TrailLayers/`에 독립 효과, `Sheets/`에 시트와 배치 정보가 있다. 기본 공격 클립은 합성본을 참조한다.
- Unity 6000.3.5f2에서 전체 440클립·3,136프레임 참조, FPS·루프·32 PPU·Point·무압축·피벗을 검사했다. 무명장수는 88클립·608프레임 모두 연결된다.
- 전체 근접 Trail 80클립·672프레임을 격리된 프리팹 복사본에서 시간별로 샘플링해 검증했다. 그중 무명장수 공격은 8클립·64프레임이다.
- 최종 무명장수 본체 608프레임의 캔버스 가장자리 접촉은 0이다. Unity 콘솔 오류 0, 제작 도구의 기존 3개 검사 통과, 서버 빌드 오류·경고 0을 확인했다.
- 열린 감천 마을 씬과 수정 상태는 그대로 유지됐다. 게임의 공격 판정·속도·Animator 전이는 변경하지 않았다.
