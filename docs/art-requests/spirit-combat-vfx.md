# 요청 목록 — 원혼 전투 이펙트 (2026-11-23)

Claude Code(구현) → Codex(리소스) 요청. 원혼 전투(평타·원혼 스킬 20종·상태이상·혼절/부활·불씨)가 구현되어 있고, 지금은 이펙트 자리를 HUD 플레이스홀더(점·사각형·글자)로 대신 그린다.

- **제작 규격·프롬프트의 원본은 Notion `설정 > 이펙트`**다. 이 문서는 그것을 복사하지 않는다. 각 항목의 파트·프레임 수·팔레트·영문 프롬프트는 링크된 요청서를 따른다.
- 이 문서가 더하는 것: ① 요청서가 **없는** 항목(아래 B), ② 구현이 각 파트를 **언제 재생하는지**(C), ③ 납품 경로(D).
- 순서는 `docs/art-pipeline.md`의 **GPT 컨셉 이미지 → 사용자 컨펌 → PixelLab** 그대로. 컨펌 전 PixelLab 요청 금지.

## C. 구현이 파트를 재생하는 시점 (납품 후 연결 기준)

| 파트 | 재생하는 서버 이벤트 | 위치 |
|---|---|---|
| Cast / Cast Loop | `S_Skill` 받음. `castTime > 0`이면 그 시간 동안 Loop, 취소(`S_CancelSkill`)면 즉시 제거 | 시전자 발밑 |
| Travel | `S_Skill.info.targetId`가 있을 때 시전자→대상 (평타 화살·침, 침 놓기, 조준 사격) | 효과 중심 |
| Impact | `S_ChangeHp` (amount > 0, heal 여부로 피해/회복 구분, critical로 B-11) | 맞은 대상 |
| Ground | 즉시 범위 스킬(호령·칼춤·길놀이·탕약 등) 발동 순간, 시전자 중심 range칸 | 칸 격자 |
| Loop (상태) | `S_ChangeStatus` duration > 0 동안. duration 0 = End 재생 후 제거 | 대상 머리 위/발밑 |
| 덫 Loop / Impact | 덫 오브젝트(FIELD) 생성 ~ 밟혀서 제거 | 깔린 칸 |
| 혼절·부활 | `S_Die`(faintTime > 0) → B-5 Loop / `S_Channel` → B-6·B-8 / `S_Revive` → 부활 Impact | 대상 |

- 프레임 수는 연출용이다. 지속시간·시전 시간·사거리는 서버 데이터가 정하고, 구현이 Loop 반복과 제거를 맞춘다.
- 강제 이동(밀치기·돌진·물러서기)은 칸을 바로 옮긴다. Trail은 출발 칸→도착 칸 사이에 한 번 재생한다.

## D. 납품 경로

- 아트: `Client/Assets/Resources/Art/Effects/<Spirit|Common>/<키>/` — 기존 PixelLab 이펙트 임포트(`Tools > ProjectY > Effects > Build PixelLab Effects`)와 같은 구성(`Sprites`, `Sheets`, `Animations`, controller, `SourceInfo.json`).
- 프리팹: `Client/Assets/Resources/Prefabs/Effect/<Spirit|Common>/<키>.prefab`. 파일명은 Notion 규칙 `VFX_[spiritID]_[skillID]_[Part]_[Dir]` / `VFX_Common_[Key]_[Part]_[Dir]`.
- 방향형은 N/NE/E/SE/S/SW/W/NW 8개, 방향 없는 것은 ALL. 메타데이터(피벗 px, fps, loop, occupiedCells)는 Notion `이펙트` 통합 규격의 필드를 그대로.
- 납품되면 Claude Code가 위 C 기준으로 연결하고 HUD 플레이스홀더를 걷어 낸다.
